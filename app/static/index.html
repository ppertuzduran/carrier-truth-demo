How to read this demo
  1. Pick a case. The frame color is the verdict: green = verified, amber = needs review, red = blocked.
  2. The four tiles are what a quote needs before anyone shows it to a client: who (client), with whom (carrier), how much protection (coverage) and how much it costs (premium). A struck-through value is not verified.
  3. Click a tile to trace it. The carrier document and the API payload dim and blur, and the exact lines the value came from are highlighted.
  4. Numbered notes explain each source. Lines connect every note to its source; a conflict note connects to both conflicting values. Hover a note to isolate it. Esc leaves focus mode.
  5. The pipeline strip shows the 7 verification layers and which one passed or failed. Hover a layer to see the tool behind it.
  • Rule: money and coverage are only true if they come from an issued carrier document. The request and the UI are claims, never the truth.
  • Fail closed: contradiction, ambiguity, placeholder, implausible value or non-authoritative source → nothing is verified and nothing reaches the client.
